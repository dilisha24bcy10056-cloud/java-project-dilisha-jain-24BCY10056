# 💰 Daily Expenses Manager

A simple, beginner-friendly Java console application to track your daily expenses, manage category budgets, and view spending reports. This project is built entirely with core Java and demonstrates fundamental Object-Oriented Programming (OOP) concepts, collections, and file I/O.

## ✨ Features

* **Interactive Menu System:** Easy-to-use console interface to navigate through different options.
* **Expense Tracking:** Add expenses with details like amount, category, date, and custom notes.
* **Input Validation:** Prevents negative amounts and ensures dates are formatted correctly (YYYY-MM-DD).
* **Daily Reporting:** Automatically calculates your total spending for the current day and provides a breakdown by category.
* **Budget Alerts:** Set a daily spending limit for specific categories. The app will warn you if a new expense exceeds your budget.
* **Data Persistence:** Automatically saves and loads your expenses to a local `expenses.txt` file using a simple CSV format. No database required!

## 🛠️ Tech Stack

* **Language:** Java SE (Standard Edition)
* **Libraries:** `java.util`, `java.io`, `java.time` (No external dependencies)
* **Data Storage:** Local text file (`expenses.txt`)
